# ecg_lancet_classification
the code package of ecg classification include 
1) model training, validation and testing
2) model loading and testing
3) test performance calculation

the implementation step:
step 1, download the package and unzip the it.
step 2, unzip the data set (records100.zip)
step 3, model training (attia_ecg_training_v1.py)
step 4, model loading and testing (attia_ecg_load_and_test_v1.py)
step 5, test model calculation (attia_test_performance.py)
